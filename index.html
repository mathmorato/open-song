Open Song Local Processor

O processador local é necessário para separar as faixas de áudio no seu computador usando inteligência artificial (Demucs).

Como Iniciar no Windows:

local-processor\start.bat

Como Iniciar no Linux / macOS:

cd local-processor && ./start.sh

Requisitos do Sistema:

  • Python 3.10 ou superior
  • FFmpeg instalado e disponível no PATH
  • Pacote Demucs (instalado via pip install -r requirements.txt)

Assim que o servidor for iniciado em http://127.0.0.1:8765, a página detectará a conexão automaticamente.
